3DCityDB-Tools plugin for QGIS: Changelog

Version 0.9.1 (2026-09-13)

Main changes

  • Client-side
    • Fixed glitch with wrongly rendered icons and text in the "Connection status" boxes of Layer Loader, Bulk Deleter and QGIS Package Administrator
    • Fixed bug in Layer Loader and Bulk Deleter when resizing extents
    • Fixed bug in Bulk Deleter when closing connetion
    • Added more visible hints on Save/Load Settings operations in Layer Loader
    • Added support for QGIS 4.2 LTR
    • Dropped support for QGIS 4.0
  • Code maintenance and clean-up

Version 0.9.0 (2026-03-16)

Main changes

This version is a branch of version 0.8.13 for QGIS 3.x. It has been adapted for QGIS 4. No additional functionalities have been added.

  • Client-side
    • Added support for QGIS 4
    • Dropped support for QGIS 3
  • Code maintenance and clean-up
